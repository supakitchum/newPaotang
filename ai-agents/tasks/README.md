# Tasks

Orchestrator เขียน task prompt สำหรับ agent อื่นในโฟลเดอร์นี้

Naming:

```text
YYYYMMDD-<task-key>-<agent>.md
```

Example:

```text
20260506-m1-platform-core-backend.md
20260506-m1-admin-shell-bo.md
20260506-m1-customer-adapter-customer.md
```

Agent ห้ามเริ่มงานถ้าไม่มี task file ที่ชัดเจนจาก Orchestrator หรือคำสั่งตรงจาก Coordinator
